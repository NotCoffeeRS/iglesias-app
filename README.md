# Iglesias App

Aplicación web para administrar una red de iglesias cristianas (mínimo 4 sedes): horarios y ubicaciones,
usuarios y roles, miembros, asistencia, eventos, ministerios, donaciones y aportaciones, gastos y costos,
comunicados y reportes. Proyecto escolar con método Scrum; entrega **2 de noviembre de 2026**.

## Cómo trabajamos

1. Todo trabajo sale de un **Issue** (lo crea el orquestador a partir del backlog). El tablero es el proyecto "Iglesias" del perfil NotCoffeeRS.
2. Una rama por Issue: `tipo/<issue>-modulo-descripcion`. Nunca se hace push directo a `main`.
3. Pull request con `Closes #n` y la entrega del agente (plantilla incluida).
4. El orquestador verifica el PR (`orquestador/verificacion`); **Marcos hace el merge (squash)**.
5. Reglas completas para humanos y agentes: [`AGENTS.md`](AGENTS.md). Decisiones: [`docs/DECISIONES.md`](docs/DECISIONES.md).
